# Blackjack Game

A simple text-based Blackjack game implemented in Python.

## How to Play

1. Run the script: `python f1`
2. You will be dealt two cards, and the dealer one visible card.
3. Choose to 'Hit' (h) to draw another card or 'Stand' (s) to keep your current hand.
4. The dealer will draw cards until they reach 17 or higher.
5. The player with the highest score under 21 wins, or closest to 21 without busting.

## Rules

- Face cards (Jack, Queen, King) are worth 10.
- Aces are worth 11, or 1 if that would cause a bust.
- Blackjack is 21 with two cards.
- Dealer stands on 17+.

## Requirements

- Python 3.x

## Troubleshooting

- Ensure Python is installed and in your PATH.
- If running remotely, clone the repo locally first.
